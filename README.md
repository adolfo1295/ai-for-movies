# AIForMovies

AIForMovies is a small Android movie app built as a public learning project about using AI agents with Android development.

## Local setup

1. Copy `secrets.properties.example` to `secrets.properties`.
2. Set `TMDB_API_KEY` to your TMDB v3 API key.
3. Open the project in Android Studio and run the `app` configuration.

`secrets.properties` is ignored by Git. Never commit API keys.

## Episode checkpoints

The project will use Git tags such as `ep01-start` and `ep01-end` so each video can link to the exact version it demonstrates.
